## CONVENTIONS GIT ET MESSAGES DE COMMIT
- **Langue :** Tous les messages de commit générés doivent OBLIGATOIREMENT être en français.
- **Format :** Le message doit être composé d'une seule phrase courte, simple et directe, toujours précédée d'un emoji qui illustre parfaitement l'action effectuée.
- **Exemples de format attendu :**
  - ✨ Ajout du modèle User personnalisé
  - 🐛 Correction du bug lors de l'ajout au panier
  - 🎨 Amélioration du design mobile de la boutique
  - ♻️ Refactoring de la logique de création des produits
  - 📦 Installation de HTMX et Alpine.js
  - 🚀 Lancement de la Phase 1
